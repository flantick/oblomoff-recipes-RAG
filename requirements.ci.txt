# A deliberate SUBSET of requirements.txt: the suite runs without network, GPU
# or docker, and the heavy libraries (torch, transformers, FlagEmbedding,
# faster-whisper) are imported lazily inside functions, so no test ever reaches
# them. Leaving them out turns a 5-minute install into a 50-second one — and
# makes CI enforce that laziness for free: a new module-level `import torch`
# fails here with ModuleNotFoundError.
#
# Versions mirror requirements.txt on purpose. CI must test the floor the
# project actually declares; pinning would keep CI green while a fresh install
# from requirements.txt is already broken.
#
